# dyhtg26

This is the repository for Do You Have The Guts? 2026

We have chosen to attempt the JPMorganChase challenge:

"Make something fun which uses two buttons or actions maximum"

Our interpretation of this is morse code, with one button being a . and one being a -

We thought we could create a nice looking webpage which could have different avenues to explore,

- tetris like typing duels, where both players are given a sentence and they have to race to finish it.

- story mode to get better at reading / writing morse code.

- type morse code to test wpm.

The menus are entirely navigatable through what we think are quite novel controls constrained to the 2 button maximum.
One button cycles through menu items while the other button selects. To go back a page you press both buttons at the same time.

While typing out morse code, there is automatically a 1 second inactivity timer to move on to the next letter when you have started typing a letter. 
To add a space you press both buttons.

To finish a letter quickly you simply hold the last symbol of a letter. for example F is ..-. where to move to the next letter you hold the last . for around 0.2 seconds (changeable)
These intuitive controls allow the typing experience to end up feeling very fluid.
